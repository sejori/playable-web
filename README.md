# playable-web — Marketing Site, Embedded Playable Demo & Creator Build Studio

Frontend application for **playable.gg** featuring:
1. **Marketing & Open-Core Architecture Showcase**: Explains "One Signed Launcher, Infinite `.pck` Realms", the 6 Genre Starter Cartridges, Procedural-First Token Economics, and Subscription + £249 Commercial Eject pricing.
2. **Embedded Interactive Playable Demo (`The Boiling Iron Rig`)**: Browser-playable 3D slice of the Action-RPG cartridge with real-time WASD movement, CoalVent_01 Metal Shield extraction, Earth Lance attacks against the Fire Warden boss, 6-Digit Room Code joining, Hold-L1 Voice Architect prompt simulation, and a toggleable **4-Panel Quad-Debug Vision Overlay** (Player Cam, Ortho Navmesh, Jolt Collision Wireframe, UI Bounds).
3. **Streamlined 4-Step Creator Build Interface**: Simple user-facing prompt-to-realm builder displaying progress across four intuitive stages (*1. Scoping & Game Design* -> *2. Systems & Procedural World Build* -> *3. Automated Playtest & Visual QA* -> *4. Packager & Realm Deploy*), backed by `playable-server`.
